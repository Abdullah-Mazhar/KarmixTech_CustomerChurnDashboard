# KarmixTech Customer Churn Prediction Dashboard

## Project Overview
Customer Churn Prediction Dashboard built during Karmix Tech Data Analyst Internship.

## Tools Used
- Python, Pandas, Matplotlib, Seaborn, Scikit-learn, Streamlit

## Dataset
IBM Telco Customer Churn Dataset (Kaggle) — 7,043 customers, 27 features

## Key Insights
- Overall Churn Rate: 26.5%
- Month-to-month contract customers highest risk (42%)
- ML Model Accuracy: 80% (Logistic Regression)

## Project Structure
- dashboard.py — Streamlit Dashboard
- Customer_churn.ipynb — Data Cleaning, EDA, ML Model
- telco_churn_cleaned.csv — Cleaned Dataset
- eda_charts.png — EDA Visualizations
- ml_results.png — ML Model Results
